AlgorithmNext process chosenTypeAdvantageLimitation

Waiting time = time spent in the ready queue (TAT − BT). Turnaround time = CT − AT, total time in the system. Response time = first CPU start − AT. Throughput = completed processes ÷ (last completion − first arrival). Priority convention: lower number = higher priority. Ties: arrival time, then input order.
