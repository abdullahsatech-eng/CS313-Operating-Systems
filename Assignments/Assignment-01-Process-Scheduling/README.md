## Overview

This assignment implements a CPU Process Scheduling Simulator demonstrating four scheduling algorithms:

- First-Come, First-Served (FCFS)
- Shortest Job Next (SJN)
- Round Robin (RR)
- Priority Scheduling (preemptive and non-preemptive)

## Features

- Process input and validation
- Gantt chart visualization
- Waiting time, turnaround time, response time, and throughput calculations
- Algorithm comparison
- Basic shared-file conflict demonstration
